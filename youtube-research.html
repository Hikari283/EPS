チャンネルを探して登録

@ハンドルやURL（youtube.com/@○○、/channel/UC○○）で入れるとAPIの消費が少なく済みます。名前だけの場合は検索で一番近いチャンネルを登録します。

キーワードで伸びている動画から探す

検索は1回でAPIの無料枠を多めに使います（1日およそ100回まで）。見つけたチャンネルは右のボタンで登録できます。

YouTube Data API キー

キーはこのPCのブラウザにだけ保存されます。

キーの作り方（無料・5分）

  1. Google Cloud Console にGoogleアカウントでログインし、上部のプロジェクト選択から「新しいプロジェクト」を作る（名前は自由）。
  2. 左メニュー「APIとサービス」→「ライブラリ」で YouTube Data API v3 を検索して「有効にする」。
  3. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」。表示されたキー（AIza…）をコピーして上に貼り付け。
  4. （推奨）作ったキーの「キーを制限」で、API の制限を「YouTube Data API v3」だけにする。
無料枠は1日10,000ユニット。リサーチ画面の更新は登録チャンネル数×数ユニット程度、キーワード検索は1回100ユニットです。

データ

取得した動画データは6時間キャッシュして、APIの使いすぎを防いでいます。
