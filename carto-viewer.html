CARTO Viewer の使い方

  
CARTO 3 の Export データを、このPCのブラウザだけで表示・解析するツールです。データは外部に送信しません。本物のCARTOではないので、診療の最終判断には使わないでください。

  
読み込めるデータ

  
    
    
  • ○○.mesh：3Dの形とメッシュ上の値（LAT、電位など）
    • 
    
  • ○○_car.txt：ポイントの座標・LAT・電位
    • 
    
  • ○○_Points_Export.xml、○○_P#_Point_Export.xml：アノテーション（Ref、LAT、WOI）
    • 
    
  • ○○_P#_ECG_Export.txt：ポイントごとの心内電位・12誘導
    • 
    
  • VisiTagExport/Sites.txt：焼灼点
    • 
  

  
フォルダごと、またはZIPのまま開けます。CARTOのバージョンでファイル形式が少しずつ違うので、読めないファイルがあれば教えてください。

  
マウス操作

  
    
    
  • 左ドラッグ：回転　／　右ドラッグ（またはShift＋ドラッグ）：移動　／　ホイール：拡大・縮小
    • 
    
  • クリック：上の「クリック操作」で選んだ動作（選択・除外・距離・ライン）
    • 
    
  • 向き：マップの下の AP / PA / LAO / RAO / LL / RL / INF / SUP をクリック（CARTO座標を +X=患者左・+Y=背側・+Z=頭側 と仮定）
    • 
  

  
波形パネル

  
    
    
  • 赤い線（LAT）をドラッグすると、LATを付け直せます。ダブルクリックした位置にも移動できます。修正するとマップを自動で再計算します。
    • 
    
  • ホイール：時間方向の拡大・縮小　／　ドラッグ：時間方向の移動
    • 
  

  
キーボード

  
    
    
  • ← →：前後のポイント　／　Delete：選択点を除外/復帰　／　Space：伝播の再生/停止　／　Esc：計測を中止
    • 
  

  
注意

  
    
    
  • 色の補間、伝導速度、分裂電位・LAVAの検出は独自の簡易計算です。CARTOの表示とまったく同じにはなりません。
    • 
    
  • このツールのスクリーンショットには、患者名は入りません。
